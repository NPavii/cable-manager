# Кабельный менеджер

Приложение для проектирования кабельных трасс и подготовки кабельной документации.
Схема прокладки в стиле Harness.Design: оборудование с выводами, клеммы и разъёмы,
мягкие ортогональные провода, кабели, заметки, печать листов А4.

## Запуск (для тестировщиков)

1. Распакуйте архив.
2. Запустите `cable-manager.exe`.
3. Установка не требуется. Windows 10/11 (x64).

## Быстрый старт

| Действие | Как |
| --- | --- |
| Добавить оборудование / источник / заметку | Правый клик по пустому полю |
| Добавить сигнал (Авария, Работа, Пауза, Питание, Связь, Воздух) | Правый клик по оборудованию |
| Клемма ○ или разъём ▸ у точки | Правый клик по точке строки |
| Проложить провод | Тянуть от порта OUT к порту IN (можно наоборот) |
| Сменить порядок строк | Тянуть за ручку ≡ в строке |
| Переименовать | Двойной клик по строке или шапке |
| Настройки кабеля | Двойной клик по проводу |
| Сгибать провод мышкой | Зажать провод и тянуть |
| Splice (общая точка для нескольких проводов) | Ctrl+клик по проводам → правый клик → «Соединить провода» |
| Цвет / штриховка / переброс на другую сторону | Правый клик по проводу |
| Дублировать оборудование | Правый клик по оборудованию → «Дублировать» |

## Навигация

- Колесико мыши — масштаб (вокруг курсора).
- Зажатое колесико (средняя кнопка) — панорама.

## Файлы

- Новый проект — Ctrl+N, Открыть — Ctrl+O, Сохранить — Ctrl+S, Сохранить как — Ctrl+Shift+S.
- Формат файла `.cbm` (JSON) — проектом можно обмениваться по почте/мессенджеру.
- При несохранённых изменениях приложение предупреждает перед открытием другого файла,
  созданием нового проекта и при закрытии окна.
- Дополнительно проект автоматически резервируется в localStorage на случай
  случайного закрытия без сохранения.

## Печать

- Ctrl+P или кнопка «Печать (А4)» — предпросмотр комплекта листов.
- Печатаются только занятые листы А4 (альбомная ориентация) со схемой размещения,
  далее — «Листы связи» (кабели: имя, тип, откуда → куда, подключения).
- В диалоге печати: «Сохранить как PDF», ориентация Альбомная, поля — Нет.

## Отмена и повтор

- Ctrl+Z — отменить, Ctrl+Shift+Z / Ctrl+Y — повторить (100 шагов истории).
- Перетаскивание, переименование и правка жил сливаются в один шаг — отмена
  возвращает состояние до начала действия целиком.

## Сетка и выравнивание

- Кнопка «▦ Сетка» включает фоновую сетку (шаг 22 px) и привязку
  перетаскивания оборудования, заметок и точек трасс к её узлам.
- ПКМ по оборудованию → «Выровнять по сетке»; ПКМ по полю → «Выровнять всё по сетке».

## Шаблоны оборудования

- ПКМ по оборудованию → «Сохранить как шаблон» — блок попадает в библиотеку
  (хранится в localStorage).
- ПКМ по полю → «Шаблоны ▸ …» — вставка копии блока с новыми id.

## Экспорт

- «Журнал CSV» — кабельный журнал (открывается в Excel: имя, марка, сечение,
  откуда → куда, подключения, длина, наконечники).
- «SVG» / «PNG» — вся схема одним файлом (PNG рендерится в 2x).
- «DXF» — схема для AutoCAD/компаса: провода — полилинии на слое WIRES
  (цвет = цвету кабеля), оборудование — контуры и подписи на слоях EQUIP/TEXT.
  Единицы — пиксели схемы как миллиметры, ось Y направлена вверх.

## Разработка

- `npm install` → `npm run dev` (dev-сервер), `npm test` (Vitest, 31 тест),
  `npm run build` (проверка типов + сборка), `npm run dist` (сборка exe).
